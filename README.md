# 🧺 Laundry Service Booking Web Application

A responsive web application for a laundry service that allows customers to explore available services, add items to a cart, calculate the total cost, and submit booking requests with email notifications through EmailJS.

## ✨ Features

- **Responsive Navigation:** Easy navigation between Home, Services, About Us, and Contact Us.
- **Hero Section:** Introduction to the laundry service with a quick booking button.
- **Service Overview:** Highlights service achievements and customer experience.
- **Laundry Services:** Browse available services and their prices.
- **Dynamic Shopping Cart:** Add and remove services with automatic total price calculation.
- **Booking Form:** Collect customer name, email address, and phone number.
- **Email Notifications:** Send booking details using EmailJS when a customer books a service.
- **User-Friendly Interface:** Simple layout designed to make booking convenient.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/tripathiAdityaDev/laundry-service-booking-web-app.git
   ```

2. Open the project folder:

   ```bash
   cd laundry-service-booking-web-app
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

### EmailJS Configuration

To enable email notifications:

1. Create an account at [EmailJS](https://www.emailjs.com/).
2. Configure an email service and an email template.
3. Add the required EmailJS configuration to the JavaScript code.
4. Test a booking to verify that the email is delivered successfully.

**Note:** Email notifications require valid EmailJS configuration. Never commit private credentials or email account passwords to GitHub.
